# Code of Conduct

This project aims to provide a respectful, harassment-free experience for everyone.

## Our Standards

We expect contributors to:

- be respectful and constructive
- welcome differing viewpoints
- focus on what is best for the community and the users

Unacceptable behavior includes harassment, discrimination, and abusive conduct.

## Enforcement

If you encounter unacceptable behavior, please open an issue describing the situation. If the report is sensitive, prefer a private channel (GitHub Security Advisory) and we will respond.
